# 🧠 Data Structures & LeetCode Practice in Python

Welcome to my repository for practicing **data structures** and solving **LeetCode-style problems** using **Python** 🐍. This repo is meant to help me (and others!) improve problem-solving skills, build algorithmic thinking, and master common coding interview patterns.

##💡 What You'll Find Here

🧩 Data Structures: Implementations of classic structures from scratch (arrays, linked lists, stacks, queues, trees, graphs, etc.)
🧪 Practice Problems: Solved LeetCode problems organized by difficulty
🛠️ Utility Functions: Helper functions and boilerplate code to speed up problem-solving
🔁 Ongoing Updates: New problems and improvements added regularly

## 🚀 How to Use

## Clone the repo:
    ```bash
    git clone https://github.com/yourusername/data-structures-leetcode-python.git
    cd data-structures-leetcode-python
    ```
## Explore and run:
  Each file is self-contained with examples and test cases.
  Use python3 filename.py to run individual scripts.
